# SankalpFrontEnd

React dashboard for Sankalpa job automation.

## Structure

```
src/
  api/api.js
  pages/       Login, Register, Dashboard, AutoApply, Logs
  components/  Navbar, StatusCard, JobTable, UploadResume
  hooks/       usePolling.js
  App.jsx
  routes.jsx
  main.jsx
```

## Run

```bash
cp .env.example .env
npm install
npm run dev
```
